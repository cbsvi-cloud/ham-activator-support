# HAM ACTIVATOR – Verified Capture

## Support / Assistenza

HAM ACTIVATOR is an application designed for amateur radio operators who perform portable activations.

The app provides tools for managing activations and creating Verified Capture photographs containing information associated with the activation, including date and time, GPS position, altitude, Maidenhead Locator and activation reference data.
